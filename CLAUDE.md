# Обязательные правила проекта

## Git

- **Коммиты — БЕЗ соавторства.** Никогда не добавлять в сообщение коммита
  строку `Co-Authored-By: Claude ...` (и любые её варианты). Владелец
  проекта явно попросил пушить без коавтора — это правило действует для
  всех коммитов и пушей в этом репозитории, без исключений.
