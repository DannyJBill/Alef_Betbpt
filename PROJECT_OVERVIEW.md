# Alef Bet — Обзор проекта

Новая версия — сверху. Верхняя запись = актуальное состояние. Детали — CHANGELOG.md; полная картина — PROJECT_STATE.md.

Что это. Telegram Mini App для изучения иврита русскоязычными репатриантами. Словарь и живые фразы вводятся раньше грамматической теории (методика Кон-Цедека): слова приходят порциями через уроки и копятся в личном словаре с интервальным повторением. Стек: React + Vite + Tailwind, Vercel (auto-deploy с main), Supabase PostgreSQL. Прод: **beta.V1.1.4.2** (schema v8); в рабочей копии сверх этого — **v1.2 части 1–2** (не закоммичено, см. ниже).

## v1.2 (часть 2) — редизайн Home: тропа курса, «Продолжить», подсказки (09.08.2026, не закоммичено)

Главный экран переписан на канонические данные графа курса (`COURSE_PATH`/`getContinueNode`) вместо своей отдельной упрощённой 3-секционной модели («Буквы»/«Огласовки»/«Словарь»), унаследованной ещё до части 1 и рассинхронизированной с реальным курсом. Новая карточка «Твой путь» — 5 остановок вертикальной тропой (пройдено всего → последний пройденный узел → текущий → следующий → ещё впереди), цвет по статусу, реальные id узлов вместо выдуманной сквозной нумерации.

«Продолжить» ведёт в контент урока напрямую — заодно найден и закрыт **BUG-022**: эта кнопка (и «Повторить» до неё) технически ни разу не была настоящим переходом, простое схлопывание таба мешало React увидеть новую команду навигации (подробности — `CHANGELOG.md`/`BUGLOG.md`). Повторение букв и слов объединено в один слот. Подсказка под маскотом берёт содержимое из реальных полей данных урока (никакого выдуманного контента ни для «Знали ли вы?», ни для новой «Как запомнить» у словарных порций). Тизер ближайшего достижения заменил полную сетку из 8 бейджей (она и так уже была в Profile).

Подробности — `CHANGELOG.md`, статус версии/файлов — `PROJECT_STATE.md`.

## v1.2 (часть 1) — модули пути, подгруппы-чекпоинты, экзамены (09.08.2026, не закоммичено)

Путь курса был одной сплошной лентой (73+ карточек). Первая часть v1.2 делит её на 5 цветных сворачиваемых модулей (Алфавит + Уровни 1–4), внутри каждого грамматического модуля — подгруппы, заканчивающиеся настоящим сводным экзаменом (не косметическим значком, а узлом графа с `requires`, реально блокирующим дальше).

**10 экзаменов** (`EX0.1` — буквы/огласовки/фонетика целиком, `EX1.1…EX4.3` — по подгруппам) не несут нового контента: вопросы собираются на лету из уже существующих `practiceItems` уроков (для грамматики) и из букв/огласовок через адаптер в тот же движок упражнений (`exercises.js`, генераторы `word_ru`/`word_he`). Рендер — существующий `ExerciseSession`, не новый квиз-компонент. Порог 80%, мгновенная пересдача.

По ходу поймана и исправлена логическая ошибка первой версии: автозачёт «кто уже прошёл материал — экзамен не блокирует» изначально стоял как живая проверка и на практике засчитывал экзамен САМ СЕБЕ в момент открытия для любого игрока (не только старого) — вынесено в одноразовую миграцию `StatsContext`, подтверждено живым прогоном.

Не в этой части: бейджи/достижения за подгруппу, связка с SM-2-повторением. Подробности — `CHANGELOG.md`, статус версии/файлов — `PROJECT_STATE.md`.

## beta.V1.1.4.2 — админка, дев-режим, клавиатура (23–25.07.2026)

Серия быстрых релизов поверх beta.V1.1.4 — без изменения версии в package.json, но с заметным приростом функциональности.

**Админ-панель** (владелец приложения). Экран внутри мини-аппа (`AdminScreen.jsx` + `api/admin.js`) и полноценный HTML-дашборд (`/api/admin?view=1`): DAU/WAU/MAU, воронка курса по урокам, отток по сегментам активности, статистика колод, топ-рефереры. Карточка пользователя — личное сообщение, выдача/отзыв Premium (навсегда / на N дней / отозвать). Рассылка по 9 сегментам (активные/уснувшие/ушедшие/premium/начинающие/продвинутые…). Доступ — по подписи Telegram WebApp (HMAC-проверка initData) для владельца без пароля, либо запасной `ADMIN_SECRET` для десктопа/локалки.

**Дев-панель / тест-режим**. Скрытый вход — 5 тапов по «Мой профиль» (`ProfileScreen.jsx`). Ползунок выставляет прогресс «пройдено до узла N, дальше закрыто» с пресетами (Зона 0 / Ур. 1–3 / Всё) — тестирование любого места курса без консоли и SQL.

**ИИ-ассистент поставлен на паузу.** `AI_ENABLED = false` в `helpers/ai.js` — вместо ответа модели показывается заглушка «бот пока в разработке». UI (ввод/кнопка) работает как обычно.

**Клавиатура.** Несколько раундов правок иврит-клавиатуры (`HebrewKeyboard.jsx`) и отдельная клавиатура для игрового режима (`GameScreen.jsx`), заведённая и дважды доправленная в течение одного дня.

**UpdatePopup.** Новый экран анонса, затем фикс размера, затем смена ссылки на канал (сейчас ведёт на `t.me/alefbetchannel`).

**Багфиксы 23.07.2026** (вшиты текстом в сам попап апдейта): белый экран после теста огласовок · краш словаря и игры · счёт в игре не сохранялся · пустая тема «Слова» · кривая отметка ответа в уроках · тофу-квадратики вместо букв в моделях · разные цифры в словаре.

**«➕ Ещё слова».** Доработка логики перехода словарь → колоды (`DecksScreen.jsx`, `ReadingScreen.jsx`).

⚠️ Известное расхождение: текст UpdatePopup обещает «🤖 ИИ-помощник — спроси что угодно на иврите», хотя фича сейчас выключена (`AI_ENABLED=false`). См. BACKLOG.

## beta.V1.1.4 — уровень 4, движок упражнений, тематические колоды (22–23.07.2026)

Крупнейший релиз с запуска: закрыты этапы 3–5 перестройки v1.0, курс вырос на треть, появился второй источник лексики.

Движок упражнений (этап 3). Типы вопросов вынесены в реестр из 6 генераторов (exercises.js) + единый рендерер (ExerciseSession). Новый тип задания = плагин, без правки экранов.

Схлопывание (этап 4). Снесены осиротевшие хабы (Alphabet/Grammar/WordsScreen), лента «Новое», узлы W1–5/P1–5, checkWordsUnlock. Прогресс пользователей сохранён через #-fallback.

Уровень 4 (seq 53–70, 18 уроков). שֶׁל и притяжательные, вопросительные слова, десятки и составные числа, прошедшее время целиком (G3.1–3.6, синтез 90%), и новый трек книги Коэн-Цедека «🧬 Система слова» (корень, модель, деятель, профессии/приборы). Курс: 58 из 108 уроков Алеф.

Тематические колоды (этап 5). Второй источник лексики: 462 слова в 15 темах, группы по 8. Хранятся в Supabase (deck_words), прогресс — в user_word_progress (снимает потолок 4 КБ CloudStorage). «📖 Изучить» — флип-карточки + тренировка без зачёта, «✅ Проверить» — квиз с зачётом. Статистика по колоде, слияние выученного в общий словарь. Гейт — после уровня 4.

Словарь переработан. Три кнопки без дублей: 🃏 Повторить · ✅ Проверить (единый комплексный квиз) · ➕ Ещё слова (колоды). Счётчики приведены к одной базе.

Чистота данных. Из 100 «фраз» 27 однословных переклассифицированы в слова: итог 216 слов + 73 фразы (+16 фраз-замков).

UX и багфиксы. Автопрокрутка «Пути» к текущему уроку + рамка активного модуля; единая подсветка правильный/неверный с паузой; починены краши словаря и игры, счёт игры, пустой пул «Слова», кривая отметка ответа, тофу-квадратики моделей.

Смоук: 200 проверок.
