# Promo

Промо-материалы и вспомогательные инструменты проекта: генераторы картинок для
постов/сторис, шаблоны текстов, брендовые ассеты и т.п. Это независимая от
основного приложения зона — сюда можно добавлять новые инструменты по мере
надобности, они не участвуют в сборке (`vite build`) и не публикуются в само
приложение.

## Содержимое

- [`tg-post-generator/`](tg-post-generator/README.md) — генератор красивых
  картинок для постов в Telegram (текст + фон/картинка + иконка/маскот,
  экспорт в PNG).

## Соглашение

Каждый инструмент — отдельная папка с собственным `README.md` и, по
возможности, самодостаточным HTML-файлом без шага сборки (открывается прямо
в браузере). Общие брендовые ассеты (маскот и т.п.) можно копировать из
`public/mascot`.
