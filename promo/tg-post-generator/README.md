# TG Post Generator

Простой генератор картинок для постов/сторис в Telegram. Работает полностью
в браузере, без сборки и без интернета — просто открыть `index.html`.

## Запуск

Двойной клик по `index.html` (откроется в браузере по умолчанию), либо:

```
start promo/tg-post-generator/index.html
```

## Возможности

- **Форматы**: пост 1:1 (1080×1080), пост 4:5 (1080×1350), сторис 9:16
  (1080×1920), wide 1200×630 (для превью ссылок).
- **Фон**: сплошной цвет, градиент (2 цвета + угол, есть готовые пресеты в
  цветах приложения) или своя картинка (растягивается по «cover» + затемнение
  для читаемости текста).
- **Текст**: метка (eyebrow), заголовок и описание — свой цвет, размер,
  выравнивание, жирность; для иврита можно принудительно включить RTL.
- **Иконка / маскот**: готовые маскоты приложения (`assets/icons`) или своя
  картинка, с изменяемым размером.
- **Подпись-футер**: например `@channel · hebrew-app.example`.
- **Перетаскивание**: текстовый блок и иконку можно двигать мышкой прямо по
  превью, чтобы расположить их как нужно. «↺ Сбросить позиции» возвращает
  дефолтное расположение.
- **Экспорт**: кнопка «Скачать PNG» сохраняет картинку в полном разрешении
  выбранного формата.

## Добавление своих иконок

Положить PNG/SVG в `assets/icons/` и добавить пункт в массив `BUNDLED_ICONS`
в `index.html` — либо просто загрузить файл через поле «Иконка / маскот» →
выбрать файл (без изменения кода).
